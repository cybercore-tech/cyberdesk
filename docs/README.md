# Cyberdesk project site

Static HTML, CSS, and JavaScript. GitHub Pages serves `main:/docs`; `.nojekyll` preserves literal template examples. No build step or remote asset dependencies.

Preview: `python -m http.server 8000 --directory docs`. Check desktop/mobile layouts, palette selection, preview buttons, and command copying.

Fonts and Cyberdesk mark are copied from Cyberdesk assets. Palettes come from the Cybercore family site’s theme data.
