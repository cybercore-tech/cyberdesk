03 / MAKE IT YOURS

Your next session
starts here.

Bring a Rust toolchain, Git, and a Markdown vault. The checkout layout below matches Cyberdesk’s current Cybercore path dependency.

TERMINAL / INSTALL 
# Run from a new workspace directory
mkdir -p core framework
git clone https://github.com/cybercore-tech/cybercore.git framework/cybercore
git clone https://github.com/cybercore-tech/cyberdesk.git core/cyberdesk
cd core/cyberdesk
CYBERDESK_ROOT="$HOME/Vaults/notes" cargo run --release
# Open http://127.0.0.1:8765

ENVIRONMENT / THE ESSENTIALS

CONFIGURATION 
CYBERDESK_ROOT="$HOME/Vaults/notes"
CYBERDESK_BIND="127.0.0.1:8765"
CYBERDESK_PUSH=0

Set environment variables when starting the server. The local address defaults to 127.0.0.1:8765.

Is this the running application?

This page is a project site with an illustrative workspace preview. The editor and vault run locally through the Rust application.

Where do my notes live?

In the directory you set with CYBERDESK_ROOT. Its default is ~/Vaults/darknotes. Start with a backed-up or scratch vault when trying the application.

Does saving push to GitHub?

Git pushes are off by default. CYBERDESK_PUSH=1 enables pushing after commits; it requires a configured repository and remote.
